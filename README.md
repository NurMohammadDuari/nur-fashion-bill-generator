A dedicated web application for generating, managing, printing, and exporting industry-standard Garment Delivery Bills, Challans, and Invoices.

## 🌐 Live Demo

**https://nurmohammadduari.github.io/nur-fashion-bill-generator/**

## ✨ Features

- **Standard Factory Bill Format**: Replicates authentic garment factory delivery challans with exact columns: *SL No, Description, Buyer, Style No, Qty in Pics, Po No, Rate/Par Pics, Amount@ BD Tk*.
- **Automatic Calculations**: Instant quantity sums, rate multiplied amounts, grand totals, and Bangladeshi Taka in words ("In Word: One Lac Eighty Six Thousand...").
- **Exact A4 Paper Standard**: Designed specifically to the international ISO 210mm × 297mm A4 standard. Always fits onto a single crisp sheet with zero multi-page spills.
- **Direct A4 PDF Download**: High-resolution 300 DPI PDF generation saved directly to your device with 1 click.
- **Standalone HTML Export**: Download single-file offline `bill.html` invoices to send directly to buyers via email/WhatsApp.
- **Factory Customization**: Fully editable company headers, factory addresses, customer name, date, bill number, notes, and authorized signatures.
- **Bills Archive**: Save and switch between multiple bills directly in your browser without losing data.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher)
- [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/NurMohammadDuari/nur-fashion-bill-generator.git
   cd nur-fashion-bill-generator
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

### Building for Production

To create an optimized production build:
```bash
npm run build
```

The output will be generated in the `dist` directory.
